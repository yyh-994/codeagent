# 博客写作技能

## 必须：委托子 Agent 完成博客

**写任何博客必须按顺序委托两个子 Agent：**

1. 先调 `blog-writer` 研究并写作：
   `task(subagent_type="blog-writer", description="写一篇关于 [主题] 的博客，保存到 back/output/blog_output/<topic>.md")`
   等待返回 → 拿到博客文件路径

2. 再调 `reviewer` 独立审核：
   `task(subagent_type="reviewer", description="审核 back/output/blog_output/<topic>.md，检查结构、逻辑、表达，有问题直接修改")`
   等待返回 → 审核通过

**禁止 blog-writer 返回后跳过 reviewer 直接结束。**

## 必须：输出结构

**每篇博客必须输出两个文件，缺一不可：**

1. 保存正文到 `back/output/blog_output/<topic>.md`
2. 调 `generate_image` 生成封面图，存到 `back/output/img_output/<topic>.png`
3. **在回复中展示完整博客内容**，让用户不用打开文件就能阅读

## 回复格式（必须 — 不遵守视为未完成）

写完并生成封面后，回复中必须包含以下三部分，缺一不可：

1. **封面图路径**：`![封面图](back/output/img_output/<topic>.png)`
2. **博客全文**：把刚写的博客完整粘贴出来（不是摘要、不是总结、不是要点），必须是完整的 Markdown 正文，包括标题、所有段落、所有格式
3. **关键要点总结**：3 条以内

**绝对禁止**：只说"博客已保存到 xxx"却不展示全文。用户需要直接在对话中看到完整内容，不需要打开文件。如果用户必须打开文件才能看到内容，任务视为失败。

## 博客结构

### 1. 钩子（开头）
- 用吸引人的问题、数据或观点开头
- 让读者想继续读
- 控制在 2-3 句话

### 2. 背景（问题）
- 解释这个话题为什么重要
- 描述问题或机会
- 与读者的实际经验关联

### 3. 正文（解决方案）
- 拆成 3-5 个章节，用 H2 标题
- 每个章节覆盖一个核心观点
- 适当使用代码示例、表格
- 列表用项目符号

### 4. 实践应用
- 展示如何应用这些概念
- 包含分步指导
- 提供模板或代码

### 5. 结论和行动指引
- 总结关键要点（3 条以内）
- 结尾给出明确的下一步行动
- 关联相关资源

## 封面图生成

用 `generate_image` 工具，topic 取消息开头方括号中标注的值：

```
generate_image(prompt="详细的图片描述...", topic="方括号中的topic值")
```

### 生图 prompt 写法

1. **主题**：画面主体是什么
2. **风格**：扁平设计、3D、等轴测、水彩等
3. **构图**：居中、三分法、对称
4. **配色**：暖色系、冷色系、高对比度
5. **氛围**：专业、科技感、温暖
6. **留白**：顶部留空放标题

## SEO 要点

- 核心关键词出现在标题和首段
- 关键词自然分布 3-5 次
- 标题控制在 60 字以内
- 写一段 150-160 字的摘要
