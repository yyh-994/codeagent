# 我的课表查询

## 工具

使用 `query_my_schedule` 查询个人课表。不要查询学生姓名、学号、成绩或学分。
当前只有一个学期，由工具读取 `academic_terms` 自动确定，不询问学期。
工具内部关联 `course_schedule` 和 `class_periods`，不需要自行生成 SQL。

## 参数和默认值

- `time_scope`：today、tomorrow、this_week、next_week、date、week、term。
- `query_date`：指定日期 YYYY-MM-DD；只在日期明确时填写。
- `week_no`：第几教学周，从 1 开始。
- `weekday`：周一为 1，周日为 7。
- `course_name`：可选的课程名筛选。
- 所有参数均可空：没有时间条件默认今天，仅星期默认本周。
- 对“第三周周三”，传 week_no=3、weekday=3，可同时传 time_scope=week。
- 对“那周四呢”，从最近对话继承明确的教学周或时间范围，weekday 改为 4。
- 优先使用当前用户消息中的“课表查询参数”，不凭空添加条件。

## 执行规则

1. 已有课表查询意图时，即使没有槽位，也直接调用工具，不追问姓名或日期。
2. 已有明确课表槽位时，也应查询，不因缺少意图标签而追问。
3. “今天”“明天”“本周”“下周”交给工具按北京时间计算，不自行猜教学周。
4. 必须先调用工具再回答，不把聊天历史当成当前排课事实。
5. 工具提示日期超出学期时，说明数据范围，不能回答“今天没课”。
6. 查询成功后，按日期、课程、节次、起止时间、教室整理结果；没有排课则如实说明。
7. 工具失败时说明失败，不把错误解释为空课表。
